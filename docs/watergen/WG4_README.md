# WG-4：四种水域构图选择

用户已认可 0.25.2 的中部视觉调整，并明确选择继续开发「四种水域构图可切换」。本轮只把现有构图接入本地设置，保留碰撞、玩法和信息权限。

## 使用

运行本地 `Releases/BaitbreakPixel-0.25.4/BaitbreakPixel.exe`，打开设置中的「生成水域 · 本地小鱼视角」，用下方下拉框选择：

| 构图 | 视觉种子 | 特征 |
|---|---:|---|
| 蕨叶庭 | 713284 | 已确认的默认方案；蕨叶与中部远景草丛 |
| 长叶湾 | 2649 | 带状长叶、不同侧重点和光域 |
| 浮叶荫 | 42 | 浮叶更宽，色调偏绿 |
| 垂根岸 | 731 | 较长垂根与不同岸侧构图 |

默认选择仍是蕨叶庭，生成水域开关默认关闭。本次启动有效，重开对局保留选择，退出应用后回到默认。关闭开关时可先选构图，不发生生成；打开时才准备。每种首次需要短暂准备，最近两种构图复用缓存。设置失败完整回退到旧水域，不留下半套图层。

联机期间两个控件均禁用，岸上和抄网观察沿用原环境。关闭开关即可即时回到旧水域；不写入个人规则、存档或网络数据。

命令行可用 `-- --water-appearance=fern`、`ribbon`、`lily` 或 `root`。`legacy` 显式关闭；无效名称不启用。原 `fern` 参数保持兼容。

## 基线与边界

任务 ID：WG-4。开发基线为 `83d6ca5724a9241399b3e4aa5dbf03e3f2017b10`，即用户刚确认的 0.25.2 水域版本；底层游戏为 P3.0/P3.1，地图公开摘要不变。

开始前已 fetch 并核对 `origin/feature/dev @ 5e04115c8bad9861935b18045d2ffd4dc2b59388`。主线新增 P3.2 NPC 觅食、摄食和快照改动，属于玩法变化；本轮按用户明确选择的构图功能范围继续冻结已确认的玩法基线，没有合入这些变化。该同步缺口明确保留，后续集成需单独解决版本记录和玩法基线，不能声称当前分支包含主线觅食版。

私有供应器维护四个公开固定 seed 及最近两套 bundle。菜单提供选择，View 只转发设置，入口解析显式应用参数；这些共享适配由本 Agent 完成。0.25.3 的选择功能未修改生成算法；0.25.4 进一步调整私有生成与烘焙，profile、碰撞、摄食、RNG、快照 schema15 和绘制顺序仍保持不变。网络脚本仅同步本地 build 为当前试玩版本。

0.25.4 根据用户反馈补充四种构图中部偏上区域的远景高草与悬垂叶簇，并添加稀疏近景叶簇和轻幅摆动。沿用原有四个种子、18 处动画和七张纹理，碰撞与玩法不变；本次验证、前后对照及包体记录见 [WG4_UPPER_REPORT.md](WG4_UPPER_REPORT.md)，首次选择功能记录见 [WG4_REPORT.md](WG4_REPORT.md)。本轮完成后等待构图切换的实际试玩反馈，不扩展岸上/联网表现，也不创建互动地图。
