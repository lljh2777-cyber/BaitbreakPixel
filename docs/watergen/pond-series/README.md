与已有「沟谷倒木」相比，分别使用岩棚、根盘、低沙洲、顺坡木四种结构组织画面；不能只换颜色或镜像一张地图。参考图中的多根交叉木、密集动物和高前景不直接照搬，中央活动空间与画面可读性优先。

“石阶”是岩层剥蚀形成的自然岩棚，不是人工台阶；后续需要继续打破平直、等距边缘。

## 每张的固定流程

1. **地势与大构图**：提供 2–3 个方向，只制作水色、光照、沙泥和木石大形体；先选择构图。
2. **植物群落**：在选定构图上增加生态关系，矮草/藻类随坡脚与沟底分布，附生物依附木石；不推定新增交互。
3. **装饰动物与氛围**：单独处理虾、蜗牛、远景小鱼及本地视觉时间；不能把食物/NPC/暗钩状态接入装饰系统。
4. **分层与合并交接**：逐图明确背景、中景装饰、前景框景和待绑定木石草；记录公开宿主、原 target 适配要求与可读性验收。

完成当前张的阶段确认，再进入下一阶段；整张交付后按顺序开始下一张。不要一次把四张的地形、植物和动物全做完。用户已选择 **M01/B**，第三轮独立装饰动物已完成。下一步为该图分层标注与真实对象适配交接，再开始 M02。

## 与主游戏的边界

延续 [场景分层与交互约定](../SCENE_LAYER_INTERACTION_MAP.md)：前景不等于可交互；图片不能生成 Authority 几何。系列编号 M01–M04 只是文档美术编号，不能写入现有地图协议。当前是全景美术概念图，不是 Godot 截图、透明分层素材或已安装的新玩法地图。

真实地图能力以主游戏最新版本为准。旧 Watergen 文档中 0.27.5 的平底坐标只是历史核对记录，不能覆盖主游戏后续真实起伏地形。接入时让美术服从最新公开 MapContext：保护可游区、巢穴、出生点、公开候选饵位、网区和 HUD；保留缠线、淡化、束草和前后绘制穿插。

只把符合现有真实 wood/stone/grass 的外观绑定为交互外观；其他坡岸、碎石、群落、垂根和装饰动物不改变玩法。旧 `feature/watergen@63112b1` 继续冻结，当前不合并到主游戏，也不发布新试玩版本。
