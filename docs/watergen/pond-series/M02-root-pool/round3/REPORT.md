## 视觉与玩法隔离

动物继承已有纯视觉采样模块，只使用本地时间和视觉种子。没有 World、NPC、食物、钩位或碰撞输入；不使用权威 RNG，不进入网络快照。不可吃、不可钓、不缠线、不挡网，也不根据隐藏钩改变运动。

植物/根系仍烘焙在单图，动物是独立图层。未来正式接入需要让蜗牛和附生植物关联公开木石宿主，保持其变换、裁剪和淡化；当前尚未绑定。粗根不因视觉体量大而成为新的交互目标或实心障碍，适配以最新真实地图为准。
