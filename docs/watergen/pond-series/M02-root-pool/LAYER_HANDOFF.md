## 后续接入次序

1. 制作背景、树基岸景、泥沙、植物、局部木石草皮肤、前景等独立资源；补齐被移走物体后的背景，防止重复叠影。
2. 读取最新主游戏公开 MapContext/Presentation，保护真实可游边界、巢穴、出生点、全部公开候选饵位、网区与 HUD。旧 Watergen 平底记录不能覆盖新版地形。
3. C01/C02/C03 当前 feature_id 均为 null；仅对已有 wood/stone/grass 适配真实 ID、轮廓、bounds、back、compatibility index、fade group 和原能力，保留缠线、束草与鱼线饵的绘制穿插。无匹配对象时重做、退远或省略美术，不新增目标，不移动真实地图来贴图。
4. 苔藻、附生物、蜗牛跟随公开宿主的变换、裁剪、淡化；虾和远景鱼保持独立装饰时间，不读取隐藏钩、食物或 NPC 状态，不写快照。
5. 以最新主游戏进行玩法及联机回归；特别验证左下近景不盖巢穴、根须不冒充鱼线、动物不冒充食物，鱼、饵、QTE 和 HUD 保持可读。

坐标仅是 1280×480 美术参考，不是蒙版、目标范围或 Authority 几何。巨型根盘不能整块当成 wood 障碍；已有第三轮预览验证不等于主游戏验收。
