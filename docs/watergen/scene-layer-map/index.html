合并时必须保留的三个边界

01 · 真实地图决定交互

已有木、石、草的 ID、形状和能力不变。这里的长倒木如果对不上地图，就重做外观构图，不把分散目标连成一个新障碍。

02 · 保留原来的绘制穿插

缠线、束草、鱼与食物已有前后绘制通道；不能简单把全部植物压到玩家上方。木石附生物使用同一宿主透明度。

03 · 可读性与隐藏信息

每张真实地图按公开巢穴、出生点、候选饵位及镜头约束布置装饰。装饰不接收隐藏钩位，不因真假钩改变布局或运动。
