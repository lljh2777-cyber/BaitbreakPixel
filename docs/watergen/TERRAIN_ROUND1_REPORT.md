# 自然池塘视觉重做 · 第一轮

日期：2026-10-06。状态：三套方向已交付，等待选择后进入植物群落阶段。

[打开三方案对照画廊](terrain-round1/gallery.html)

## 本轮改了什么

从新构图开始，仅参考用户图片的像素块面、青绿水体、柔和斜光、非对称池底和远近对比；没有使用当前游戏水下背景作为生成输入。内置 image_gen 生成三张原创方向稿，每张 2048 × 768，使用时映射到 1280 × 480 世界尺度。

| 方案 | 地势与大形体 | 判断 |
|---|---|---|
| A 沟谷倒木 | 左侧长缓坡、偏右低谷、右侧短坡；低位倒木与右侧石群 | 最接近“自然沟谷 + 大形体锚点”的目标，建议优先 |
| B 石坡沙湾 | 左侧大石坡、中央开阔沉积沙湾、右侧小木桩 | 中央留白最大，画面最舒展 |
| C 根盘斜沟 | 右侧沉木根盘、斜向浅沟、左侧低对比沉木 | 纵深和偏侧构图最强，右侧密度较高 |

三套都以不同长度的坡面、侵蚀缺口、半埋石块与沉积层构成池底，避免周期波浪、对称鼓包和等距石群。远景压低饱和度和对比，底部近景保留清楚的像素材质，中央水体低细节。

本轮不添加植物、浮叶、活体垂根或动物。C 的根盘是沉木的一部分。已有 WG-6.2 植物保持原文件，没有叠加到新稿中。当前三张是静态方向稿，尚未拆成能独立视差或摆动的生产图层，也没有替换真实地形或正式游戏入口。

## 查看方式

画廊可以切换 A/B/C，并对照左、中、右镜头的纯画面与识别样本。原生预览：

```powershell
& 'E:\Fish_catches_people\aquatic_system\BaitbreakPixel-watergen-v2\tools\watergen\Open-Terrain-Directions.ps1'
```

- `1/2/3`：选择方案；`Tab`：全景 / 640×360 游戏尺度镜头。
- 方向键：平移；`Home`：回到中部；`G`：构图留白参考框。
- `P`：静态识别样本；`Esc`：退出。

鱼使用现有 `pixel_art.gd` 的玩家贴图。三种食物色块、细线、QTE/HUD 使用固定公开外观值构造，仅用于检查对比与干扰，不是正式游戏状态，也不是完整 QTE/食物验收。

## 如何保证不影响玩法

生产 `scripts/`、主场景、地图数据、项目配置和协议文件零修改。新预览没有创建 World，没有地图、钩、观察、网络或快照输入。唯一现有绘制依赖是玩家像素贴图工厂；使用它不会读取玩法状态。预览自身没有碰撞节点，不消费 world/NPC RNG，不读隐藏钩信息。

三张图片始终绘制在识别样本之前，HUD/QTE 样本绘制在独立不透明面板上。正式入口不引用新预览。旧 `feature/watergen@63112b1` 继续冻结；正式版本保持 0.27.5。
