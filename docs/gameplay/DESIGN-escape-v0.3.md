# 2D 环境辅助脱钩方案（历史提案，已替代）

> 本提案基于 0.2 的实体绕障玩法，已被用户后续指定的“草木石可穿行、接触变淡、空格 QTE 主动缠一圈”方案替代。0.3 实际行为以对应历史版本的 README 和试玩说明为准；当前入口见 [项目首页](../../README.md) 和 [试玩说明](PLAY.txt)；下文仅保留设计讨论记录，不是待实现清单或当前规则。

本文件是下一轮设计建议，未修改 0.2 的游戏行为。目标是让玩家能理解并完成“带线绕障 → 障碍承担拉力 → 游近制造松线 → 移动中 QTE 吐钩”，同时保留持续高张力断线。

## 当前缺口

`pond.gd` 的 `_step_line` 使用整条线路长度计算一个总张力。绕障后基础值由 0.50 改为 0.38，尚未独立计算钓鱼者一端和鱼嘴一端的张力。`rope.gd` 每次求当前最短可通行路线，没有保存上一次绕过障碍的方向与接触顺序。因此，当前的“绕根”主要是几何避障，尚未构成稳定的卡线玩法。

另外，全部实体都连接池底，侧视画面中的鱼常常必须从很高的顶部绕行。高张力又能快速导致断线，玩家可能在完成绕行前就已经脱钩，缺少主动选择环境策略的理由。草丛、木石的重叠也让可穿过的草叶看起来像一堵墙。

## 玩家能完成的动作

示例：鱼上钩后从一根短斜枝上方游到背面，鱼线贴住斜枝的真实边缘。线在接触处出现小亮点，钓鱼者一段仍然绷紧。玩家向这个接触处靠近，使鱼到斜枝的线路缩短，剩余鱼线形成松弛。鱼端张力条下降；低张力稳定后出现圆环判定，玩家边调整位置边按 E 吐钩。

绕到障碍背面本身不直接赠送低张力。需要玩家移动产生松弛，障碍的作用是暂时阻碍钓鱼者把这段松线收走。另一个选择是向外持续用力，保持高张力三秒拉断线。

## 障碍的不同作用

| 类型 | 鱼怎样通过 | 鱼线怎样接触 | 适合的用途 |
| --- | --- | --- | --- |
| 草叶与细茎 | 可穿，轻微减速，叶片弯曲 | 产生较弱且短暂的阻力，过度拉扯会滑脱或扯开 | 容易接近的短松线机会 |
| 粗草根、木枝和木根 | 实体阻挡，沿侧面或上沿绕行 | 整段轮廓都能接触；转折较大时更稳定，枝杈较强 | 稳定地制造松线并完成 QTE |
| 石头 | 实体阻挡，沿表面滑行 | 圆滑面容易滑动，棱角更容易维持转折 | 改变拉线方向，辅助持续拉紧 |

不增加需要瞄准的预设挂线按钮或固定亮点。接触位置来自实际鱼线与表面的位置关系，小亮点仅用于显示已经发生的接触。水草通过线接触叶茎的方式提供软阻力，不能因为鱼进入一个区域就无条件卡线。

细草不会无限制承担拉力。草被扯开只解除这次接触，鱼仍然上钩；只有成功吐钩或鱼线真正断裂才解除上钩状态。石头磨损、嘴部受伤等可以后续扩展，首轮不增加第三套脱钩规则。

## 鱼线与张力

第一阶段采用轻量的分段线路。保留现有多边形轮廓和可见图作为避障工具，增加持久的有序接触记录。记录障碍、接触所在边、沿边位置和绕行方向；鱼继续移动时，接触点可以沿表面滑动，并按需要追加新的接触。

将线路视为“钓竿 → 接触点序列 → 鱼嘴”。各段保存可用线长和松弛量，新增接触时分配已有线长，移除接触时合并线长，避免凭空生成松线或突然收走一段线。最靠近鱼的接触点决定鱼端最后一段的拉力方向；钓竿侧收放线先影响上游，能否传到鱼端取决于接触的滑动阻力。

接触轻微时可以滑动；材料阻力足够时短暂维持；两侧拉力差过大时再次滑动。阻力取决于材料、转折程度和接触持续时间。这是可调的游戏近似，不要求模拟完整软绳物理。

接触不能因为重新求出的直线路径更短就消失。正常释放需要鱼沿原方向反向绕回，并且邻接两段合并后可连续扫过无遮挡区域；也可由细草扯开、成功吐钩、断线或重开清除。不能仅凭一个角度瞬间翻转或松线就删掉接触。已经存储的路径失效时暂停并修复几何，不能画一段穿过实体的直线作为退路。

钓鱼者继续缓慢自动收放线，但反馈应有短暂延迟，接触只延缓传递，不永久免疫拉力。保持高张力的策略需要持续逆向游动；加入适度拉回与伸长限制，避免无限伸长后停着等待三秒也能轻松断线。保留高张力阈值和三秒目标，不用取消这一条路线来强迫玩家绕障。

## 建议的首轮调试值

这些是待试玩调整的初值，并非已经实现的规则。

| 项目 | 初值或原则 |
| --- | --- |
| 低张力判定开启 | 鱼端张力低于 25%，持续 0.5 秒 |
| 低张力判定失效 | 鱼端张力高于 35%，持续 0.2 秒，避免边界抖动反复开关 |
| 成功操作 | 保持移动能力，指针进入白区时按 E；沿用现有圆环节奏 |
| 高张力断线 | 鱼端实际张力至少 90%，连续 3 秒；中途不足则中断连续累计 |
| 初次绕线稳定确认 | 约 0.15—0.25 秒持续接触，且确有线路转折 |
| 草茎机会 | 正常操作能争取约一轮 QTE 的机会，不能永久挂牢 |
| 实体通道 | 以带钩碰撞宽度为基准，主要练习通道至少留 45—55 逻辑像素 |

按 E 的当帧，先更新鱼身碰撞、鱼线路径和实际张力，再结算 QTE。若同帧已经被捕，不能再授予脱钩成功。入口吐钩判定仍然锁住移动；低张力圆环仍允许移动。松线判定失败后保持上钩，冷却后可以再争取机会。

## 场景与反馈

第一处练习障碍应是钩饵附近的一根短斜枝，绕行距离短，上方和背面留出带钩鱼能活动的空间。第二处放较稳定的分叉木根，用于练习维持松线；第三处放软草丛，提供更容易进入但更短暂的机会。避免大部分可用接触都挤在池底。

之后再考虑离底横木和上下双通道；自由悬浮障碍会带来更多绕线方向，需要在持久接触验证稳定后加入。背景植物降低对比度，真实木石边缘保持清楚；鱼经过草丛时局部草叶变淡或向两侧让开，避免把软草误读成硬墙。

沿用一个鱼端张力条，不再增加常驻的钓竿张力条。钓竿侧和鱼侧分别显示绷紧或弯曲的线形；接触处短暂闪光，并使用轻微音效与草茎弯曲说明是否承力。状态只保留“接触滑动 / 卡住 / 可以吐钩 / 即将断线”中的当前一条。松线弯曲也必须避开实体，无法安全弯曲时用分段闪动表达松弛，不能让表现层重新穿模。

## 实施顺序与验收

1. 先做一根短斜枝、一只鱼和一个钩的练习场，完成持久接触、分段线长、鱼端张力和低张力 QTE。玩家能在三十秒内理解并主动复现一次。
2. 验证绕行、反向绕回、贴近顶部与底部、变向和冲刺。不得穿模、无条件丢失接触、凭空产生线长；脱离接触不等于鱼脱钩。
3. 接入缓慢收放线，检查闲置不能永久保持松线；同时保证移动中完成一轮 QTE 的机会真实存在。持续拉紧断线依旧可行。
4. 加入草茎与石头材料差异，再把通过验证的障碍组合放回主池塘。同步验证补饵、抄网、回巢和重开。

几何验收除静态端点扫描外，还要保存完整移动轨迹，检查每一帧接触顺序与线段扫过的区域。覆盖多接触顺序、障碍根部、连续绕行与退绕、失焦暂停、不同帧率和判定边界。需要手动试玩确认玩家理解与手感，不能仅凭自动测试断言这套机制已经好玩。
