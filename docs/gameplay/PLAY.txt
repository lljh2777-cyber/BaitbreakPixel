吃饵，不上钩 · 像素池塘 0.23.1

当前为 0.23.1 Phase 1.5 本地人工试玩修正版，不是公开发行版。Phase 2 仍冻结。
运行 BaitbreakPixel.exe；首次启动若被 Windows 安全提示拦截，请自行检查来源后决定是否运行。
本轮必须由你人工确认，自动测试不代表手感、动画清晰度或趣味性已经通过。
自行构建后启动：双击 BaitbreakPixel.exe，保持同目录的 BaitbreakPixel.pck 不移动。

0.23.1 场景：错落岩坡、长茎荷叶和垂根、远中近景视差、沙砾通道与深色近景草叶。
鱼进入木头任一相连部分时，整棵木头的主干、枝干与根系统一变透明，离开后一起恢复。

本次更新
0.23.1 加入饱食与主观警惕：不进食会降低恢复能力，极饿会产生能主动反向抵抗的觅食偏移。
HUD 显示饱足 / 饥饿 / 很饿 / 极饿，以及平静 / 迟疑 / 警觉。警惕来自可见运动和扰动，低警惕不保证安全，高警惕也可能误报。鱼钩只在新饵或重新挂饵事件决定，同一个 bait_id 生存期间不会突然换真值。
设置增加饥饿开关、本能强度与鱼钩危险度；不包含自动吸食脉冲。权威快照为 schema 13，联机双方需同为 0.23.1。鱼客户端接收经过角色裁剪的表现数据，不能接收隐藏钩状态或随机种子。
水体背景改为细腻渐变与柔和斜光；远处水草和倒枝有轻微视差。水底增加沙泥、落叶和接地阴影，巢穴改为树根洞口，食物达标后入口亮起并显示回巢箭头。
吸食时游速默认降到当前模式的 68%，松开后平滑恢复；慢游、冲刺和上钩后都生效。可在设置 → 游动 → 吸食游速倍率中调整。
吸食分为轻吸、稳吸、猛吸：滚轮调节，顶部显示当前节奏。轻吸更容易剥外层，颗粒吸入较慢；猛吸更快拉近整团并剥落内层，也更容易将隐藏鱼钩拉到嘴部。
饵团沿吸动方向轻微拉伸，流线速度和颗粒拖尾随吸力增强；食物真正入口时嘴部短暂闪光，食物数值亮起。
钩饵与散饵整团都会被吸向鱼嘴：两类饵料共用相同的吸力曲线与响应速度，吸力越大位移越明显；饵粒继续逐层脱落并进入嘴部。
设置中的“饵团吸动倍率”统一影响整团位移；松开吸食后平滑回摆，旧数值方案仍可导入。
水域扩大到 1280×480，逻辑画面保持 640×360，镜头跟随鱼游动；巢穴离开画面时有方向箭头。
增加倒木、根系、错落石堆和疏密水草；鱼可穿行，木石继续阻挡抄网。
鱼看不到未咬钩的鱼钩、吊线、钩尖及饵料身份标签，只能看见同样外观的饵团。咬钩后仍显示拉线和 QTE。
开局饵位每局变化；鱼单人同时有三团饵，人类对局有两团普通饵，投钩后增加钩饵。
观察镜头跟随钓位和放线深度；与 0.20 不能混连，双方都需 0.23.1。

设置玩法数值
标题或暂停菜单 → 设置 → 玩法规则；局内 F2 / F3 也能打开。
左上选择类别；搜索框跨类别搜索；“只看修改”显示偏离默认的选项。
每项有默认值、单位、说明、数字输入和滑块，可单项还原、还原本类或全部默认。
“保存，下局使用”保留当前对局；“保存并重开”立即开始使用新规则的一局。
返回或按 Esc 且未保存时，放弃该页草稿。编辑中的设置不会修改正在进行的 QTE。
练习和挑战都使用已保存规则。
“方案 / 导入导出”可以保存命名方案，同名会覆盖；复制 JSON 后可保存为文本或分享给朋友，也可粘贴 JSON 导入草稿。
导入后需返回设置并保存。未知格式或字段会提示错误；越界数值和不合理组合会校正。
食物目标不能超过四团饵料总量；成功区长度由成功窗口秒数和轨道时长共同计算。

小鱼操作
WASD / 方向键：游动；鼠标决定朝向，镜头随鱼移动。
左键：吸食并减速；滚轮：调节吸力，选择轻吸、稳吸或猛吸；Q：慢游。
按住鼠标右键：持续冲刺，持续消耗体力。
空格：所有 QTE。听提示音准备，浮漂进入绿色区间时按一次。
E：满足食物目标后，沿巢穴方向箭头返回，在薄荷色巢穴内回巢。
水草、木根、石头允许鱼穿过；接触时略微透明。
上钩后接触障碍物，按空格开始缠线 QTE；保持接触并游动抗拉，再于绿区按空格。
成功时鱼绕障碍游一圈并缠上线。靠近线圈制造松线，保持低张力并完成脱钩 QTE；也可持续拉紧将鱼线拉断。

钓鱼人操作
A / D：左右移竿；鱼线、浮漂受惯性和水阻随后移动。
Q：下钩；饵耗尽或断线后重新挂饵。
W：收线；S：放线。咬钩前后都能调节，并有左手操作渔轮动画。
持续收线最终把鱼拉出水；过紧可能断线，过松会给鱼脱钩机会。
F：有缠线时尝试解线；W/S 保持设置中的张力区间，空格完成 QTE 后退开最近一圈。
E：进入短暂水下观察；左键选起点 A，再选终点 B。可以从可达水域的空处起网。
再次按 E 取消规划；观察超时也会退出，两种情况均进入冷却。提交后路线锁定，松键不取消。
选好 B 后回到岸边，先出现入水预警，再沿 A→B 扫网。木石截断路线，预览显示实际可到位置。
鱼从正面开口进入网袋会被捕获；侧面/背面擦网只推开并短暂减速，鱼仍可操作。
观察时可以 W/S 控线；挥网和撤网期间左手持网，暂停主动摇轮，鱼线仍保持拉力。
默认观察 2.5 秒、退出后冷却 6 秒、预警 0.5 秒，均可在“抄网”分类修改。
鱼在挥网时仍可能吃饵、咬钩和完成 QTE，可利用木石掩护或提前避开路线。
双方上钩发力过程中会持续有机会触发 QTE，成功短暂加力，失败短暂脱力。

通用操作
H：帮助；Esc：暂停菜单；R：重开；F11：全屏。
自由练习按 N 可试抄网；Esc → 改练小鱼 / 钓鱼人可切换角色，切换会重开。
默认小鱼挑战：6 分钟内吃满 60 食物，回巢停留 2 秒；练习默认目标 18 食物。
默认钓鱼人挑战：在时限内提鱼出水或抄网捕获；鱼回巢或活到超时则人类失败。
这些目标、时限和停留时间均可修改，也可以关闭挑战倒计时。

双人联机
双方均需 0.23.1 版本。支持一条鱼对一个钓鱼人，局域网或同一台电脑开两次。
房主先在设置保存玩法方案，再创建房间并选择角色；另一人填写房主 IP 和端口加入。
同机测试地址 127.0.0.1，默认端口 24712。
准备前点“查看房主规则”，可查看全部数值与修改项。房间规则锁定，更换时退出重建房间。
双方准备后开始；联机打开菜单不会暂停世界。
音量、全屏及各自离线方案互不覆盖。离开房间后恢复个人已保存规则。

存档
个人设置和战绩保存在 Godot 的 user://pixel.cfg，命名方案位于同目录 rules-presets 文件夹。
旧版时间窗口与练习参数会自动迁移到新版规则。
默认 640×360 逻辑像素画面，窗口可放大；保留原有鱼、岸边手臂、鱼竿及绕线动画。


0.23.1 人工试玩顺序（约 5–10 分钟）
1. 选择钓鱼人：开局应显示未下钩，没有已部署浮漂/鱼线；A/D 能移动持竿位置。
2. 按 Q 完成第一次下钩，等落水后分别按住 W、S 各 1 秒：应收短/放长鱼线，手、卷线器和线上的运动方向有区别。
3. 松开 W/S，应短暂制动后停止；同时按 W/S 应停止。未下钩、判定阻断或达到长度极限时，不应假装收放线。
4. A/D 左右速度是否合适？本轮默认由 72 改为 90 像素/秒（+25%）。旧档会保留原设定；若仍是 72，可在 F2 的收放线设置中只把鱼竿左右移动速度改为 90。无需重置其他偏好。
5. 重开一局：恢复未下钩，旧动作不残留。
6. 选择鱼：体力/饱食两条是否易读，警惕单独一行是否仍挤；吃东西/等待后饱食条应增减。
7. 尝试不同警惕状态：文字是否清楚，是否仍只是主观警惕而非确定钩检测器。
8. 有条件时同版本双人联机，双方切换角色复查 Q、A/D、W/S 和重开。
