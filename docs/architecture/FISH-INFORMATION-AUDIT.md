# Fish information boundary audit

Scope: Phase0–1 one-fish prototype. Observed attachment/contact is a gameplay outcome, not concealed pre-contact bait truth.

## A — private truth

- Bait hook boolean, hook/rod assignment, deterministic slot parity: hook rolls now occur on lifecycle events and public bait IDs do not encode the roll
- Hook body/idle line: absent from fish bait rendering; exact visible grain shape is shared
- Simulation RNG, seed, creation truth logs, future supply and internal suspicion values: authority/replay only; fish transport must be explicitly projected before Phase1 network acceptance
- New authority fields: FishObservation copies explicit fields, never entire bait/grain dictionaries

## B — legitimate physical evidence

- Water-relative external bait motion, recent disturbance, visible grains and actual feeding results. Visible self-induced suction displacement is compensated before the suspicion model reads motion; it is not automatically treated as new danger evidence
- Physical flutter has overlapping full support for safe and hooked food; no amplitude interval guarantees either truth
- Actual mouth entry/attachment, visible line tension after attachment, QTE and escape feedback are action outcomes
- Cast/reel/tackle movement can occur with either safe or hooked payloads. There is only the existing main rod; no added dual-tether system
- Caution is a subjective, smoothed three-band interpretation. Hunger changes willingness to take risk, not the underlying evidence

## C — presentation noise and usability

- Pixel grain flecks and silhouette use separate deterministic decoration, not simulation RNG
- Supply warning flash applies independently of hook truth; it is a world event cue rather than a hook marker
- HUD shows satiety/caution categories, not a hook probability or precise suspicion number
- Native acceptance compares hidden-only truth flips at identical physical state and separately checks readability of all caution states

## Known boundaries

A player hosting authority can inspect authority memory; remote-role filtering is not a claim of protection from a malicious host. The held-out simple motion classifier is diagnostic evidence of useful/noisy clues, not a proof against every classifier or arbitrarily long inference. Human playtesting remains required to accept control feel and the central decision loop.
