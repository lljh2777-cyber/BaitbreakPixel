# 0.20 主动抄网

抄网不要求上钩。E 进入有限时长的水下观察，左键选 A，再选 B；提交后回到岸边，网沿锁定的直线扫掠。观察不中断世界；取消或超时也冷却。提交后不能拖动、转弯或取消。

## 模块边界

- `net_simulation.gd`：规划、可达范围、预览截停、接触、网边推力、捕获与撤回；不读 Input、不绘图、不访问存档。状态保存在 `world.net_action` 和已有网字段，世界仅保留薄调用接口。
- `net_observation.gd`：水下观察的像素轮廓、限视野和 A/B 预览。与鱼世界共用坐标，屏蔽自身 HUD 下方点击；不显示鱼方体力、食物或 QTE。
- `local_input.gd` / `game_commands.gd`：E 为一次 toggle，左右键松开不取消路线；左键点击为 point。生产鼠标点击仅在观察且未命中 HUD 时进入命令流。
- `angler_rig.gd`：处理已校验的操作。观察可 W/S；实际持网阶段暂停主动摇轮，拉力和惯性仍由原钓组系统计算。暂停/失焦/断线取消尚未提交的观察。
- `net_motion.gd`：本地显示姿态、入水/回收弧线、网袋阻尼、鱼/岸双视角的网柄连接点。扫动时水下网口严格跟随判定位置，动画不回写模拟；暂停不推进、重开清除惯性。
- `net_visual.gd`：固定网框、疏菱形网格、木柄/金属接头、水纹/水滴与握网手。复用原来的像素手部素材；岸边被捕获的鱼绘制在网袋前后层之间。
- `pond_view.gd` / `shore_view.gd`：调度动画模块，保持鱼竿、鱼线及预警可见。
- 规则目录、校验、设置、持久化仍由 0.19 的独立模块负责。

## 状态与判定

观察 → A 已选 → 提交并退出观察 → warning → sweep → miss/ caught → withdraw/提鱼 → rest。

观察及 A 保存在可序列化的 `net_action` 中；世界 `net_state` 仅描述实际网具。进入观察要求网具空闲、未在抛钩/提鱼、冷却结束。退出观察开始冷却；冷却完成但网仍在撤回时不能再开。

- 预览和实际路径使用同一障碍检测。水中可选起点，必须空得下网，并存在可提网的通道。两个端点受竿端可达距离限制，路径受最短/最长距离限制。
- 网沿 A→B 运动；网口朝 B。鱼相对网口从正面穿过入口，进入袋内深度后捕获；开始就重叠、侧擦、背面穿入均不会直接捕获。
- 最多按 1/120 秒子步检查鱼/网的相对移动，防止高速漏判。侧后方一次抄网最多产生一次推力和短暂减速，鱼仍能操控，冲量持续衰减。
- 无接触时间累计、捕获概率或网内 QTE。低体力通过已有游速/抗拉影响逃离能力。
- 撤回沿实际扫过的路径返回，再沿已检查的提网通道离水，不沿鼠标新位置走捷径。
- 实际挥网不禁止咬钩、吃饵或鱼方 QTE；捕获才结束这些动作。人类解缠在提交网具时被打断，未完成的线圈不被删除。

## AI 与联机

AI 使用同一观察、起点校验、预览、提交和接触规则。仅在可见范围内读取取整的鱼影与粗略速度，采样后作出一次预判；扫网不再追踪鱼的实时坐标。N 抄网练习也调用此流程。

快照 schema 9、联机 build 0.20；双方需要更新。观察计时、A、锁定路线、入口记录、擦网冲量与减速均纳入快照。E 和点击经可靠有序消息传送，每个事件拥有单调编号；重复点击事件不会被当成第二点。模拟独立于客户端视角，远端观察点击也使用原始 2D 世界坐标。直线扫网位置可插值；0.20.1 对撤回插值动画时间，再在原权威折线路径上采样，避免抄近路穿过拐角。被捕获的鱼与插值网袋同步。动画状态不加入网络协议，0.20.1 与 0.20 兼容。

当前观察隐蔽是显示层和 AI 的规则，客户端仍接收完整世界快照；本版未实现竞技反作弊所需的服务器信息裁剪。

## 规则迁移

JSON 规则版本升为 2，继续导入版本 1。原体力、QTE、鱼线等数值原样保留。旧抄网的展开、自动预警、固定扫网时长、持续接触捕获及疲劳捕获修正选项退役，迁移时忽略；新选项补默认值，不留可调但无效的 UI。

默认观察 2.5 秒、退出观察冷却 6 秒、预警 0.5 秒、网速 160 像素/秒、可达 340 像素、视野 380 像素、路线 30–200 像素、擦网冲量 85 像素/秒、减速 0.35 秒至 70%。旧配置中仍有效的自定义值（如网速、网大小、冷却）继续保留。默认值用于起始体验，后续平衡需双方游玩验证。

第一版未加入曲线路径、水草拖慢网、网内挣脱或复杂网兜物理。
