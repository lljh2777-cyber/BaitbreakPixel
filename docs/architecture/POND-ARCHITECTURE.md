# 0.21 水域、镜头与饵料可见性

地图为 1280×480，逻辑视口仍为 640×360，窗口放大采用整数像素缩放。水域面积约为原版的三倍；鱼和素材不缩小。

## 坐标与模块

- `pond_layout.gd`：地图大小、水面与底部、鱼边界、巢穴、候选饵位、草木石轮廓。鱼可穿过掩体，木石仍阻挡抄网；缠线目标直接来自这些轮廓。
- `pond_camera.gd`：鱼镜头跟随鱼，并在地图边缘停止；观察镜头随钓位和放线深度移动，不随隐藏的鱼移动。双向坐标转换同时用于显示和输入。
- `pond_scenery.gd`：像素水体、远景、底部碎石与巢穴。远景只装饰；可互动物体使用 Layout 的几何数据。
- `pond_view.gd`：用镜头平移绘制水下世界；鱼自身的旋转、绕行变换叠加到同一平移。HUD、QTE、提示和离屏巢穴箭头留在屏幕坐标中。
- `shore_view.gd`：将整片新水域映射到岸边透视，并提供准确逆变换。手臂和鱼竿继续使用原有素材与刚性握点；浮漂保持独立惯性。
- `pond.gd`：单机与远端鱼输入均先转换鼠标坐标；观察点击也先做屏幕 HUD 屏蔽，再发送世界坐标。

植物有独立的 `y` 根部高度，可生长在底部、倒木和石堆上。精灵缓存、接触范围、线圈变形、岸边轮廓共用此高度。绕障碍动画的边界使用地图大小，避免深水或右半地图的鱼被旧视口限制拉回。

## 水体与远景层次（源码分支）

`pond_water_art.gd` 生成两张 1280×480 原生像素纹理：细粒度水体渐变与边缘渐隐斜光，以及稀疏的远处泥坡、水草和倒枝。`pond_view.gd` 在初始化时缓存两张纹理，重开与绘制继续复用；不读取或推进世界 RNG。

远景以镜头偏移的 10% 水平、4% 垂直补偿作轻微视差，实际木石、水草和输入继续使用原有世界坐标。上中层大部分仍为空水域；远景草木只装饰，不加入碰撞、缠线或抄网目标。水体绘制仅用于鱼视角，钓鱼人观察的显示权限沿用原逻辑。

`pond_scenery.gd` 添加少量沙泥纹理、低矮的断续床沿、落叶和落地木石的接地阴影；根洞巢穴继续使用 `(60,401)` 与原回巢条件，食物达标时亮起入口并显示箭头。玩法边界、几何、规则和 schema 12 保留。当前发行版与联机 build 为 0.22.2。验证与本地包见 [水体层次测试报告](../test-reports/TEST-REPORT-WATER-DEPTH.md)。

## 水底障碍物外观（源码分支）

木石仍由 `pixel_art.gd` 在 `PondLayout.SOLIDS` 的原始多边形内部逐像素绘制。新增 `prop_image()` 让缓存纹理与回归测试共享同一输出；木纹沿每段枯木的弯曲主轴生长，包含局部暗树皮、风化节疤及倒木断口。石头使用不重复的明暗体块、稀疏细裂纹和水浸苔藻，保留原来的遮挡边界。

`pond_plant_art.gd` 只负责水草像素绘制：带状叶片渐细并显示折面，细叶水草交错生长；前后景保持低饱和的层次差别。原有茎中心线、8 帧缓存周期、裁剪范围、根部坐标、透明遮挡和缠草变形均保留，绘制不使用或推进随机源。

本次没有改变地图、抄网碰撞、缠线目标、吸食、QTE、规则或联机 schema/build。验证及前后图见 [障碍物外观报告](../test-reports/TEST-REPORT-OBSTACLE-ART.md)。

## 隐藏鱼钩

鱼视角不绘制未咬钩的钩体、吊线、钩尖亮点及“有钩饵 / 散饵”身份标签。抛饵保留饵粒，隐藏对应的线和钩尖。各饵团使用相同的颗粒绘制规则；钩体大小不影响未咬钩的画面。

0.22.0 的钩饵与散饵整团都会向嘴部移动，物理与显示共用 `suction_feel.gd`。设当前吸力为 p，整团位移倍率为 p × (0.55 + 0.45p)，响应速度为 18 + 46p² 像素/秒；目标幅度仍乘锥体强度、26 和 `hook_suction`，松开后以每秒 38 像素平滑回摆。外层、内层、核心的剥落增益分别为 p^0.8、p^1.6、p^2.2，脱落颗粒速度为 `pellet_speed` × (0.4 + 0.6p)。全部公式不读取钩饵身份，位移应用到实际饵团中心、附着颗粒和钩尖接触位置。

每团饵保存 `suction_offset`。下一帧先扣除上一帧的吸动位移，再推进原有水流或钓具运动，随后施加新位移，避免累加偏移或污染鱼竿惯性。咬钩与重新抛饵清零偏移，实际咬钩仍触发原 QTE。钓具的被动下沉与线长约束继续保留。规则标识 `hook_suction` 为兼容 JSON v2 保留，设置名为“饵团吸动倍率”；脱落颗粒使用独立的 `pellet_speed` 并受吸力影响。

显示层按实际 `suction_offset` 拉伸、收窄饵团；松开吸食时形变随偏移回摆。锥体内流线数量、亮度与速度以及自由颗粒拖尾随吸力变化。食物确实计分时记录 `last_eat_at`，用于嘴部 0.16 秒闪光及食物数值 0.18 秒高亮；暂停冻结此反馈，绘制不写回模拟。网络插值共同平滑吸力和吸动偏移。

0.22.1 将 `feeding_speed` 从仅上钩时生效改为所有有效吸食状态生效。倍率默认 0.68，在常速、慢游或冲刺的目标游速上只乘一次；上钩后的疲劳与发力倍率仍分别计算，松开吸食后沿原加速度恢复游速。水流、鱼线和擦网冲量保持独立。规则字段与 schema 12 不变。

咬钩、进食和鱼线拉力仍由原模拟判定。咬钩以后保留拉线、张力、QTE 与缠线提示。未咬钩时隐藏钩体是角色显示规则，客户端依然接收完整快照。

开局由世界 RNG 在候选位置中洗牌，为四个饵槽分配位置；同一局的双方获得相同饵位。鱼单人模式同时显示一团钩饵、两团普通饵；人类对局先显示两团普通饵，投钩后再增加钩饵。另一钩饵槽作为后续补饵。饵料总收益和目标约束沿用既有规则。

鱼 AI 对所有可吃饵团使用相同的距离判断和接近距离，不再读取钩饵身份来规避取食。鱼单人模式的钓鱼人沿岸巡游；是否看见鱼及抄网预判继续使用原观察限制。

## 联机与验证

固定地图标识改为 `pond_v2`，快照 schema 12，联机 build 0.22.2。旧版本无法与本版混连；规则 JSON 仍为版本 2，已有个人玩法方案可继续使用。网络的目标和点击范围使用地图大小，不能再把右侧输入截到 x=640。

吸食减速验证见 [0.22.1 测试报告](../test-reports/TEST-REPORT-0.22.1.md)；吸食手感验证见 [0.22.0 测试报告](../test-reports/TEST-REPORT-0.22.0.md)；整团吸动验证见 [0.21.2 测试报告](../test-reports/TEST-REPORT-0.21.2.md)；扩大水域验证记录见 [0.21.0 测试报告](../test-reports/TEST-REPORT-0.21.0.md)。历史测试中的固定地图位置、根部高度和旧投影阈值由 0.21 夹具适配，旧测试文件保留。
