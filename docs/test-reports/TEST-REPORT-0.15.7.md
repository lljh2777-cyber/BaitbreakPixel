# 0.15.7 第一人称持竿构图

日期：2026-09-28。Windows / Godot 4.7.2 / Compatibility OpenGL。

## 改动

按参考图将握竿手放在右下角，只露出短袖口。身体支点移到画面下方，肘部和长前臂保持在游戏画面外。沿用现有像素素材、112×112 像素层及 16 色调色板。

保留手、前臂和上臂的独立刚性旋转及固定骨长。左右极限之间手部转角为 15°、前臂为 23°，上臂约 9.10°；腕部相对前臂的转角限制为 ±4°。没有用整张贴图平移代替关节动作。

手腕固定在逻辑高度 y=300，竿尖随摆竿形成小幅弧线。竿身统一调整为 160 个逻辑像素以匹配参考图比例，左右各位置长度一致，张力只改变弯曲。浮漂的水平活动区域、控制按键、抄网、QTE、物理及联机协议未修改。
