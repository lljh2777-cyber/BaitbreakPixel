# 0.21.0 扩大水域与隐藏鱼钩验证

日期：2026-09-30。环境：Windows、Godot 4.7.2 / GL Compatibility，640×360 逻辑像素、1280×720 原生窗口。所有游戏检查使用 `--test-profile`。

## 改动

- 世界扩大到 1280×480，鱼镜头滚动，角色和像素素材尺寸保留；离屏巢穴提供方向箭头。
- 18 块木石、22 丛水草构成枯木根系、倒木、石堆和草岸。植物根部可位于不同高度，显示、接触、缠线和退线共用根部数据。
- 鱼看不到未咬钩的钩体、吊线、钩尖或饵料身份；抛饵也隐藏钩线。咬钩以后保留张力、鱼线与 QTE。
- 饵位由每局权威 RNG 洗牌；鱼单人同时有三团饵，人类对局在投钩后也有三团。鱼 AI 不再用钩饵身份偏好食物。
- 鼠标、观察 HUD 屏蔽、岸边逆投影与远端点击适配新地图。观察镜头跟随钓位与放线深度。
- 地图 `pond_v2`、快照 schema 10、联机 build 0.21；规则 JSON v2 保持兼容。
