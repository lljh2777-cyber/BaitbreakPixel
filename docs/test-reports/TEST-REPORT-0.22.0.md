# 0.22.0 吸食取舍与反馈

日期：2026-09-30。环境：Windows、Godot 4.7.2 / GL Compatibility。所有检查使用隔离的 `--test-profile`。

## 调整

在钩饵与散饵整团都能被吸动的基础上，加入吸力选择的取舍。轻吸较慢地拉动整团，优先剥落外层；猛吸更快拉近整团，加速内层与核心剥落，并提高脱落颗粒的吸入速度。隐藏鱼钩也随实际饵团移动，因此猛吸更容易把钩尖带到嘴边。

`suction_feel.gd` 提供共同曲线，不读取鱼钩身份。设吸力为 p，整团位移增益为 p × (0.55 + 0.45p)，接近目标的速度为 18 + 46p² 像素/秒；外层、内层、核心的剥落增益分别为 p^0.8、p^1.6、p^2.2，脱落颗粒速度为 `pellet_speed` × (0.4 + 0.6p)。整团仍保留此前的被动运动与平滑回摆。

鱼视角加入沿实际吸动方向的饵团拉伸、随吸力变化的流线与颗粒拖尾。颗粒真正进入鱼嘴时记录 `last_eat_at`，短暂点亮嘴边与食物数；HUD 显示轻吸、稳吸或猛吸及百分比。绘制不改变权威世界，暂停时反馈冻结。远端插值同步吸力与整团偏移，摄食时间随快照同步。

快照 schema 升为 12，联机 build 为 0.22.0，双方需运行本版。128 项规则、已有规则数值与 JSON v2 格式保留；相关设置帮助文字解释新的吸力响应。
