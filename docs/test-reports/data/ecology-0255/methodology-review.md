直接的四状态数字也应保留：

- survival/挑战/Mixed 的 NoNPC → Foraging → Hookable 食物为 51.918 → 44.880 → 49.818；回巢为 6/25 → 4/25 → 10/25
- duel/挑战/Mixed 的对应食物为 34.926 → 32.388 → 28.086；回巢为 1/25 → 5/25 → 4/25
- 挑战 BiteOnly：survival 的 NoNPC/Passive 各 3/25、Foraging/Hookable 各 0/25；duel 四状态均 0/25。它是明显不利的策略结果，不能略掉；该策略没有玩家 QTE/逃脱技能，不应为让这一机器人达成指定胜率而调参数
- 600/600 练习回巢也不等于零竞争成本。survival 练习 Mixed 的 Foraging − Passive 局时为 +5.863 s [1.109, 11.491]；SuckOnly 为 +9.575 s [3.501, 16.598]

食物差和胜率差方向可以不同：终局风险、达到目标后的回巢、对手行为和实际观察时长共同影响终局摄入。不要从单项平均值推断统一的“更容易/更困难”。`SuckOnly` 是既有控制器偏好名称；生产自动 Bite 仍可能发生，并非关闭该机制的纯吸食干预。

## NPC 钩事件与实际机会

300 场 Hookable 的账目严格闭合：

- 220 次实际 NPC 附着 = 164 次捕获 + 15 次逃脱 + 0 次断线 + 41 次玩家比赛先终局时仍占线
- 164 次捕获 = 125 次真正出现的新 ID 补鱼 + 39 个终局时仍在等待的捕获槽
- 142/300 场有 NPC 附着，覆盖 24/25 种子；所有 15 次自然逃脱均在 duel/挑战，其他分层不能据此声称获得自然逃脱覆盖
- 累计 NPC 占线 1,281.333 s；93 场在本 tick 开始时已被 NPC 占线的 tick 内获得玩家摄食，共 496.500 点，550 个有摄入的 tick
- survival/挑战/Mixed 每场占线 6.359 s [4.431, 8.249]，期间玩家平均摄食 3.708 [2.178, 5.340]；duel/挑战/Mixed 对应 9.155 s [5.883, 12.733]、1.812 [0.798, 3.042]
- 最长单场累计占线 40.967 s：73601、duel/挑战/SuckOnly，最终玩家被网捕。最高占线比例为 46.30%：73610 同分层，占线 19.400/局时 41.900 s

这证明占线成本和可利用机会确实出现；不证明占线期间每一份摄入都是 NPC 的因果收益。41 个未解附着存在，因此总占线除以 220 **不是**“平均完整处理时间”；原始行没有逐次附着的完整历时。自然断线为零仍是覆盖缺口，受控真实操作门单独提供机制证据。

## 审查意见

本数据没有揭示必须修正的食物归属、钩生命周期或补鱼账目故障。保留原参数、把这些有利和不利差异交给 Phase 3 最终人工试玩，是可辩护的阶段结论；不能改写为已证明真人平衡或趣味。

观察型三个鱼控制器、一个指定钓鱼人方案、默认三 NPC 和有限种子限制了外推。2/4 密度、饥饿关闭与真实输入另由集成/原生门覆盖，不能称为本 1,200 场的自然统计分层。若以后依据人工反馈改参数，需重新冻结，不能用本留出样本继续优化后仍称其为独立留出。
