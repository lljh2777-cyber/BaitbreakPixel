## 新增原生测试

`phase03_npc_hook_native` 从真实嘴部接触进入 NPC 中钩，覆盖：

- 一根共享鱼线，起点为当前鱼竿，末端为选中 NPC 的真实嘴部；NPC 位移和转向后仍精确跟随
- 玩家仍为 FREE，不借用玩家缠线/提鱼姿态，玩家所有不透明像素仍压在 NPC 前面
- hooked / landing / escaped / broken 四结果，在鱼端、岸边、抄网观察三个视角均进行固定 tick 重复渲染、权威不变、未接触钩真值与 NPC 私有 AI/计时污染、公共副本像素等价验证
- NPC 真实提鱼流程、被捕获后消失、无孤儿鱼线、新 ID 重生，以及逃脱/断线后 NPC 仍活动
- 钓错鱼不结束主比赛，不触发玩家提鱼/胜利或增加 NPC 名字、状态条

测试中的提鱼夹具先把已中钩 NPC 放在合法提鱼边界，再让真实 authority 进入和推进 lift；它不是一次完整人工操作的成功率/手感证明。逃脱/断线画面通过正式 authority release 入口建立，完整物理阈值、W/S 操作和重放在无窗口套件另行验证。
