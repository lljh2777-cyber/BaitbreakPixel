# 0.17.0 受力弯竿与抬手

2026-09-28，Windows / Godot 4.7.2 / Compatibility OpenGL。

## 改动

上钩后，以鱼线张力驱动竿身弧度。保留原始像素竿纹理和约 109.59 个逻辑像素的材料长度，使用 48 个等长段形成从较硬根部到较软前段的连续弯曲。竿根第一段与握柄方向相切，相邻纹理段共用边缘，避免强弯时出现裂缝。鱼线起点使用实际弯曲后的竿尖。

手腕随张力最多抬高 14 个逻辑像素，握柄同时旋转 6°，保留原有左右移动弧线。左手、渔轮和右手从同一姿态计算连接点；手掌和手指不局部变形。右侧衣袖在画面外延续，抬高手后也不会露出素材截断边。无张力的上钩状态保留轻微抬手，松线、脱钩及捕获后逐渐回落。

负载与抬手分别平滑跟随，首次 60 Hz 更新抬腕约 1.75 像素，避免上钩瞬间跳动。保留 0.16.1 双手比例与 0.16.2 咬钩前后 W/S 动画；没有替换或生成美术素材，没有改变实际收放线、鱼移动及捕获规则。

新增 rod_load / rod_lift 两项同步状态，完整快照 schema 升至 6，网络构建系列升至 0.17；远端显示对这两项状态插值。联机双方必须更新至 0.17。
