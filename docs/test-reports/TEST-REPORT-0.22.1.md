# 0.22.1 吸食时游动减速

日期：2026-09-30。环境：Windows、Godot 4.7.2。检查使用隔离的 `--test-profile`。

此前 `feeding_speed` 仅在已经上钩时影响游速。本版将减速应用到所有有效吸食状态，常速、Q 慢游和右键冲刺都生效。默认倍率为 0.68，即基础目标游速分别从 70、26、140 降至 47.6、17.68、95.2 像素/秒。沿原加速度平滑减速，松开吸食后恢复当前游动模式；吸食本身不会使静止的鱼自动移动。

上钩后的疲劳与发力倍率仍独立计算，吸食倍率只乘一次；水流、鱼线拉力和擦网冲量仍各自作用。设置中的“上钩进食速度倍率”改名为“吸食游速倍率”，沿用原字段、默认值及范围，已有个人方案和房间规则继续适用。快照 schema 保持 12，联机 build 升至 0.22.1，双方需使用本版。
