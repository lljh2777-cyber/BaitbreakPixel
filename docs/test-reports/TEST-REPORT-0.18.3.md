# 0.18.3 水草缠绕外观

2026-09-29，Windows / Godot 4.7.2 / Compatibility OpenGL。

## 改动

水草不再沿矩形接触区域画大椭圆。显示层按接触高度找到中央及相邻的实际草茎：草尖稀疏处束住一两根，低处束住几根。单圈螺旋的进出端相差 5 逻辑像素，近侧为低饱和单像素线，远侧更暗并藏在草后；取消粗描边闭合圆环的悬空观感。木石的原线圈几何、解线时序及手部动作保持。

绑定水草采用原缓存像素素材，局部聚拢并随拉力略微弯曲，整行根部固定。草茎和线圈共用形变数据，不会各自漂移。小鱼围绕同一束茎完整绕行，嘴、钩、线端同步连接。清除水草矩形提示框和缠点的“有钩饵”重叠文字；底部接触提示及 QTE 继续保留。

水草解线沿新的小螺旋反向退开，仍使用 0.7 秒及原起停节奏；缠线仍为 0.85 秒。所有变化只在显示层，物理接触点、移动、拉力、AI、QTE、快照和网络协议不变，继续使用 0.18 / schema 7。
