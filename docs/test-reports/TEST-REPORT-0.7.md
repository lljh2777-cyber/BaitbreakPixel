# 0.7 验证记录

日期：2026-09-26。Windows，Godot 4.7.2，Compatibility / OpenGL 3.3。

本次改动：持续收鱼与真实拉力；缠线判定和绕圈中保留游动；抗拉消耗体力、低体力削弱游速；上钩仍可取食补体力但吸食减速；挑战 / 练习提鱼动画与结算。

## 逻辑回归

`tests/smoke.gd`：137 项通过，0 失败。

- 三个不同起点的鱼不输入任何移动，均被拉到钓线起点并提离水面；挑战以 landed 失败。
- 相同场景按 30、60、120 Hz 模拟，捕获时间差小于 0.2 秒。
- 练习被提走后保留食物、回巢边，清除上钩状态和路径，不计入成功脱钩。
- 缠线 QTE 中不操作会被拉动；反向游动保持接触可以成功，消耗体力；游离目标取消判定。
- 绕圈动画继续绘制，同时允许移动，鱼端拉力继续作用；完成后移动保持松线，再 E 吐钩。
- 普通抗拉耗体力，停止对抗恢复；耗尽时普通游速也下降，不能按住反向键无限恢复。
- 上钩状态下实际吸取饵粒、增加食物与体力；吸食时游速下降，颗粒继续去重。
- 练习 0% 力度关闭牵引与收放线；恢复默认立即继续收鱼；挑战忽略练习配置。
- 连续高张力 3 秒断线、松线 QTE、入口锁定、抄网、补饵、保存设置和完整挑战仍通过。
- 提鱼动画可暂停；捕获锁定后不能靠移动取消；重开清空新状态。
