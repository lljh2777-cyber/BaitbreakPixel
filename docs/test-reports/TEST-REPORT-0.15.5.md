# 0.15.5 横向持竿动作与完整像素前臂

日期：2026-09-28，Windows / Godot 4.7.2 / Compatibility OpenGL。

## 改动

0.15.4 虽保持了固定竿长，但大幅旋转使横向控制看起来像向右上举竿。手与卷线轮贴近底栏，前臂显示不足，握柄和竿身的比例也不协调。

本版改为以水平位移为主的持竿姿态，整个输入范围内转角约 3.4°。手腕放到 y=264，手、指尖、卷线轮及摇柄与底部操作栏留出空间。竿身固定长度为 210 个逻辑像素。套筒轴向单独标定，不再用手腕到套筒的偏移向量推算竿身方向。

使用内置图像编辑工具为原像素手素材补全整个前臂，完整 PNG 使用同一个刚性变换。新显示层为 112×112 / 16 色 / 最近邻采样。素材、输入图和完整最终提示词在 `assets/first_person/HAND-FOREARM-GENERATION.md`；旧素材保留。

世界移动范围、浮漂水平活动面、钩饵物理、收放线、QTE、抄网与网络协议未修改。

## 验证

- `tests/hand_rig_v0155.gd`：3 档张力 × 3 档发力倍率 × 952 个往返姿态，12 项检查通过。除固定长度、刚性变换、套筒切线和连续性，还验证手指、手掌、袖口和摇柄不被底栏遮挡，以及姿态与竿尖高度范围。
- 总竿长实测 209.99948—210.00055；最大相邻帧端点位移约 0.466 像素。
- 无负载往返时竿尖高度变化约 16.707 像素。不同方向的鱼线牵引仍会弯竿，满负载组合中最大高度跨度约 46.37 像素；测试要求受力竿尖保持在近水区域，不把这种正常弯曲当作横向抬竿。
- `tests/shore_v015.gd`：17 项通过。新动作的屏幕位移较小，D 的可见位移断言相应更新；世界水平方向限制、W/S、坐标反解、抄网路径和提鱼端点检查保留。
- 发布包 `shore_native_v015.gd`：16 项图像及原生操作检查通过。
- 发布包长度与姿态回归：12 项通过。
- 发布包像素层读回：112×112、16 色、无半透明边缘像素。

上述几何测试不能证明美术品质。另行检查了左右极限、中间姿态、手部放大图及实际操作录像的关键帧，确认已消除本次指出的大幅举竿、底栏切手和粗糙袖子补接。

## 录像与文件

通过游戏 Movie Maker 录制 640×360 / 60 FPS，共 1,536 帧。实际运行下钩、完整右移、停顿、反向左移、回中、上钩 W 收线及 S 放线指令。检查了往返和受力阶段的 6 个录像关键帧，以及发布包静态截图。

- `artifacts/hand-motion-v0155.mp4`：完整 25.6 秒游戏录像。
- `artifacts/rod-sweep-v0155.gif`：录像第 2—19 秒的正常速度往返片段。
- `artifacts/hand-left-limit-v0155.png` / `hand-right-limit-v0155.png` / `hand-closeup-v0155.png`：最终发布包截图。

FFmpeg 仅编码录像，没有修改画面中的手臂或鱼竿。所有检查使用 `--test-profile` 与隔离配置；包测试在自身发布目录加载 EXE/PCK，没有指向源项目的 `--path`。最终构建、录像、发布包运行日志无脚本或资源错误。

本版只调整表现层及素材，没有重复跨进程联机回归，兼容标识继续使用 0.15。
