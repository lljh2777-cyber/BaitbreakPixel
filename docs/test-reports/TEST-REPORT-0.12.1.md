# 0.12.1 钓鱼人及鱼竿外观更新

日期：2026-09-26。Windows / Godot 4.7.2 / Compatibility OpenGL。

## 修改范围

- 新增 `scripts/angler_visual.gd`：缓存像素头部和马甲贴图，绘制草帽、头发、背包、口袋、靴子、前后手和卷线轮。步幅由实际岸边位移驱动；卷轮由收放线状态驱动；受力和下钩改变身体及鱼竿姿势。暂停时动作随世界时间停止。
- 连续贝塞尔竿身绘制握柄、金属导环和竿尖，末端始终采用 `angler.anchor()`。动画参数只存在于视图，没有新增世界状态或网络快照字段。
- 对局岸边增加木栈道，让人物完整显示在两种顶部 HUD 下方；联机状态移到右下角，避免遮挡最右侧的角色。
- 人物及鱼线摆动按世界的移动钓组规则显示，因此联机小鱼视角也能看到对手。抄网光标及路线预览仍由本地钓鱼人显示。手动抄网杆的显示起点对齐伸出的手。
- 游戏菜单、构建默认目录及玩法说明更新到 0.12.1。联机协议兼容标识仍为 0.12；本次未执行跨版本联机测试。
