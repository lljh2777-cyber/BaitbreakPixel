## 关键结果

- E 按下与松开只开始一次观察；第一点与第二点分开接收，同帧两点也保持顺序。
- 观察期间世界前进，鱼能移动；W/S 仍可控线。取消和超时消耗冷却。
- 提交后额外点击、旧拖动或取消消息无法改变 A→B；障碍预览与实际停止点一致，撤回不会穿过木石。
- 正面进入袋内捕获；初始重叠、侧面和背面不直接捕获。擦网推力衰减、减速恢复，不锁住移动。
- 挥网期间可咬钩；已上钩的线和拉力保留。左手持网期间停止主动摇轮。
- 旧规则 JSON v1 可迁移至 v2；退休捕获时间参数不会留在 UI 中，新参数补默认值。
- 本机 ENet 两端观察状态、A/B、捕获、提鱼和胜负一致；重复操作事件不被执行第二次。
