# 0.15.3 持竿动作结构修复

日期：2026-09-27。Windows / Godot 4.7.2 / Compatibility OpenGL。

## 原因与修复

旧实现围绕固定手腕旋转，再按纹理位置递减袖口顶点的转角。大幅向右移竿时，手掌与袖口的角度差很大，导致网格局部挤压和折叠。

本版删除这层权重网格。像素手、握柄、卷线轮和前臂使用同一个刚性变换，从位于游戏区域下沿之外的前臂支点转动。根据目标竿尖求出持竿角度，所有局部长度、面积方向和手腕关系保持不变。袖子不再单独固定、拉伸或扭曲。像素素材及 80×80 / 16 色显示层保持。

显示中的竿尖水平活动面从 y=167 抬到 y=130，使右侧极限仍留有竿身长度，控制轴仍只有左右。浮漂横带、世界中的鱼线起点、收放线、抄网路径和碰撞不变。竿身曲线的第一条切线沿握柄套筒方向，根部不会折角；上段弯曲按投影长度限幅，避免短投影在高张力和脱力时反折。
