# 0.15.9 固定画面与真实摆竿动作

日期：2026-09-28，Windows / Godot 4.7.2 / Compatibility OpenGL。

## 修正

0.15.8 将钓鱼人的横向移动抵消到水下投影，手部的可见位移很小，固定水下物体却跟着横移。本次移除所有依赖钓鱼人位置的显示偏移。

水面使用固定透视：远处浮漂活动区较窄，近处水下物体展开；坐标只取决于世界位置，与按键、手部及鱼线无关。抄网绘制、鼠标逆变换和近水范围共用这一固定投影。

手腕由画面外固定支点驱动，沿弧线移动；左右全程手腕横移约 207.91 个逻辑像素，握柄旋转 18°。现有鱼线摆动状态提供小幅、衰减的惯性跟随。手的位置不再由浮漂反推，鱼、鱼钩和浮漂移动不能抵消摆竿。

沿用图 2 提取的像素手、握柄、卷线轮及短袖口，未生成新素材。竿身使用原纹理，受力弯曲保持材料长度；模拟规则、按键及网络协议不变。

## 验证

- `tests/arm_motion_v0159.gd`：10 项通过。实际输入 D 一秒，手腕横移约 23.79 像素；同时检查固定石头投影和同一鼠标位置的逆变换完全不变。
- 同一测试在 3 档张力 × 952 个连续往返姿态下检查竿长、连接、手部刚性、可见性、固定投影及反向连续性。线竿夹角约 37.65°—60.73°，相邻采样最大关键点位移约 0.559 像素。
- 增加浮漂独立移动检查，确保钩饵换位置不会拖动手部。
- `tests/shore_v015.gd`：17 项通过，包含 W/S、左右控制、抄网路径、投影逆变换与提鱼。
- `tests/hand_joint_native_v0156.gd`：沿用原文件名，42 个实际绘制姿态的手、握柄、卷线轮和袖口像素连通性全部通过。
- `tests/shore_native_v015.gd`：18 项通过。新增真实 D 按键后的手部位移检查，以及固定动画时间下水下静态区域截图的逐像素一致性检查，防止再次通过背景平移掩盖手部不动。原生抄网拐角、取消及鱼视角检查保留。
- 最终 EXE/PCK 从发布目录再次执行 10 项动作检查和 18 项原生检查，全部通过。

实际游戏录像为 640×360、60 FPS、1,536 帧（约 25.6 秒）。检查了左端、中段、右端、回程、回到左端及高张力收线的 7 个关键帧，前景手与鱼竿具有清楚可见的位移，静态水下环境保持位置。GIF 为录像第 2—19 秒、正常速度。

测试使用 `--test-profile` 和隔离配置，没有修改玩家存档。最终构建、录像及发布包测试日志无脚本或资源错误；未重复跨进程网络测试，协议保持 0.15。
