# 0.15.6 持竿关节动作

日期：2026-09-28。Windows / Godot 4.7.2 / Compatibility OpenGL。

## 改动

0.15.5 把持竿角度变化限制在约 3.4°，主要依靠整张贴图横移，导致手臂看起来像一张平移的图片。

本版为身体支点、肘、腕建立二维关节关系。身体支点固定，上臂和前臂分别保持固定骨长；求解肘部位置后，各自使用独立的刚性旋转。握竿手、握柄和卷线轮作为完整的刚性层跟随手腕，手腕相对前臂的调整限制在约 ±4°。左右极限之间手部转角为 15°，前臂为 23°，上臂约 49.4°。

沿用原像素素材，在绘制时通过纹理坐标划分手、前臂和上臂，并用像素布料覆盖肘部与袖口衔接。没有重新生成图片，没有对手部顶点作不同角度的权重扭曲。112×112 / 16 色像素层保留。

鱼竿固定长 210 个逻辑像素，从握柄套筒沿其轴向伸出。无负载时竿尖沿 y=112 的水平活动面移动，手臂关节配合这一运动。张力继续影响竿身弯曲。物理、按键、抄网、QTE 与联机协议不变。

## 验证

- `tests/hand_rig_v0156.gd`：3 档张力 × 3 档发力倍率 × 952 个连续往返姿态。9 项检查通过：固定身体支点和骨长、腕部角度限制、手部不变形、各关节确实转动、竿长、连接切线、水平活动面、可见性及换向连续性。
- 实测竿长 209.99950—210.00049；最大相邻帧关节或竿段端点位移约 0.955 像素。
- `tests/hand_joint_native_v0156.gd`：在透明视口真正绘制手臂，采样 21 个左右位置 × 2 个卷线微动相位，共 42 个姿态。从手掌像素进行连通性搜索，检查腕、前臂中点、可见肘点及上臂中点能连接到屏幕边缘，42 项通过。这用于发现关节贴图断开的情况，补充单纯的几何测试。
- 上述几何与透明像素连接检查在独立发布包中再次通过。
- `shore_v015.gd`：17 项通过，包含世界坐标投影、水平方向、W/S、抄网路径与提鱼端点。
- 发布包 `shore_native_v015.gd`：16 项图像及原生操作检查通过。

几何与连通性通过不代表美术品质达标。另行查看了左右极限、手部放大图与实际游戏录像中的 8 个关键帧，确认上臂与前臂确实有不同角度变化，袖口和肘部没有可见断缝。

## 动画

实际游戏录制 640×360 / 60 FPS，共 1,536 帧（约 25.6 秒）。操作包括下钩、右移、停顿、反向左移、回中，以及上钩后的 W 收线和 S 放线。

- `artifacts/hand-motion-v0156.mp4`：完整游戏录像。
- `artifacts/joint-sweep-v0156.gif`：第 2—19 秒的手臂局部，正常速度，最近邻放大；没有重新绘制画面。
- `artifacts/hand-left-limit-v0156.png`、`hand-right-limit-v0156.png`、`hand-closeup-v0156.png`：静态姿态截图。
- `artifacts/hand-motion-*-v0156.png`：录制时的关键帧。

测试均使用 `--test-profile` 与隔离配置。发布包测试从发布目录加载 EXE/PCK，不通过 `--path` 读取源项目。最终构建、录像及发布包测试日志无脚本或资源错误。没有重复跨进程网络回归，0.15 系列协议标识保持。
