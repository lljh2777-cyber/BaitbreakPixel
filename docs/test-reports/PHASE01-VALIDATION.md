# BaitbreakPixel 0.23.0：Phase 0–1 开发与验证报告

## 1. 已实现范围

- 单局稳定的 fish / rod / bait / hook ID；重挂、重新部署产生新 bait_id，存活期间不翻转钩真值
- 显式 FishObservation 白名单；鱼的食物显示、选食与警惕读取合法线索，隐藏字段不随新权威字段自动扩散
- 权威快照从 schema 12 一次升级到 13，保留重放、身份和必要的新状态
- 饱食度 0–100、分档 HUD、低饱食体力恢复降低；没有新增大幅减速、视野收缩或操作延迟
- 本能仅加入有上限的运动偏移，默认最大 0.35、硬上限 0.45；单位反向输入仍保留至少 55% 的指向分量
- 按 bait_id 的 suspicion、独立 risk tolerance、快升慢降和状态/目标切换滞回；CALM / UNEASY / ALARMED 可见
- 事件随机钩、可配置危险/安全数量约束；当前可食用目标与尚未部署的备用饵分开处理
- 原有主鱼竿的 tackle 身份与内部钩状态分离，无钩载荷也能正常部署；没有增加第二根竿或双系绳玩法
- 鱼客户端的独立表现载荷与原子验证/应用；隐藏钩、钩分配、随机种子、生成真值日志、内部评分及对手 QTE 目标不发送给鱼端
- 真实 60 Hz 批量对局、统计 CSV/JSON、可复现种子、原生截图、实际 ENet 验证

没有实现：完整 AI 鱼群、多鱼竿、跨局记忆、咬食扩展或自动吸食脉冲。自动吸食仍须先通过运动偏移试玩后另行决定。

## 3. 没有隐藏初次失败

第一版谨慎机器人仅对目标选择加入警惕惩罚，仍沿用原来的近距离吸食姿态，还可能在摄食过程中改选目标。种子 1001–2000 的 1000 对完整对局给出了负面结果：

| 指标 | 仅距离 A | 初版谨慎 B |
|---|---:|---:|
| 鱼胜率 | 87.9% | 86.0% |
| 实际挂牢事件率 | 39.1% | 40.2% |
| 平均摄食点数 | 56.67 | 56.40 |
| 摄食尝试中止比例 | 9.61% | 12.56% |

这轮没有通过“警惕具有实际策略价值”的门禁。数据完整保留，未挑选有利种子，也未修改隐藏概率来制造提升。

随后只做了一次有依据的策略修正：根据有效警惕保持稍大的吸食距离，并避免无谓地中断正在进行的进食。新种子 2001–2050 的 50 对探索性试验较好，但它同时改变了进食承诺，因此没有把这次探索结果当成最终因果结论。

数据：[初次负面结果](PHASE01-FIRST-POLICY-1000.json)、[探索性 50 对](PHASE01-PILOT-50.json)、[未匹配控制的留出结果](PHASE01-UNMATCHED-HELDOUT-1000.json)

## 4. 最终匹配控制：1000 对留出种子

最终 A/B 都启用相同的进食承诺；A 忽略警惕，B 使用合法线索形成的警惕来选目标和调整接近距离。新种子为 **3001–4000**，双方各 1000 局，全部完成，零剔除、零删失。

B 的共享开关重构未改变行为：在 10 个确定性种子上，旧/新 B 的 **21,274 个完整指令逐字节相同**，再复用其同一批留出结果；匹配后的 A 单独完整重跑了 1000 局。

| 指标 | 匹配控制 A | 谨慎 B | B−A 配对 95% 区间 |
|---|---:|---:|---:|
| 鱼胜率 | 87.1% | 92.3% | +3.5～+7.0 个百分点 |
| 实际挂牢事件率 | 42.4% | 21.5% | −23.9～−18.3 个百分点 |
| 平均挂牢次数 | 0.528 | 0.225 | −0.342～−0.265 |
| 平均摄食点数 | 56.57 | 57.85 | +0.83～+1.75 |
| 平均局时 | 41.61 秒 | 38.96 秒 | −3.23～−2.07 秒 |

区间来自固定随机源的 2000 次配对重采样。局时包含成功回巢，不能解读为“越长越好”的生存时间。

结论限于：**在这组固定环境、规则和机器人中，使用警惕调整实际决策的策略有可测量的价值。** 这不是对所有策略、高手对战或人类趣味性的证明。完整旧 FishBrain 的逃脱/QTE 仍共用已有权威辅助接口；这里保证的是新增选食/警惕逻辑不读取钩标签，不宣称整个旧 AI 已变成纯 FishObservation 代理。

数据：[匹配对照](PHASE01-MATCHED-1000.json)、[A 完整指标](PHASE01-DISTANCE-1000.json)、[B 完整指标](PHASE01-CAUTIOUS-1000.json)

## 5. 线索有用，但不是答案

安全与危险饵的物理摆动分布具有相同取值范围，存在重叠；模型读取实际可感知运动，不读取 hook 真值。自身吸食造成的位移被补偿，避免把自己的动作直接当作新增危险证据。

一个简单的运动线索分类器，用种子 1–500 选阈值、501–1000 测试，共 1500 个留出目标：

- 准确率 74.47%，AUC 0.817
- 164 次误报，219 次漏报

这支持“线索有信息、存在误判”，但不是对所有分类器或无限观察时间的信息安全证明。

数据：[信息诊断](PHASE01-INFORMATION-DIAGNOSTIC.json)
