# 0.10 惯性钓组与手动抄网验证

日期：2026-09-26。Windows / Godot 4.7.2 / Compatibility OpenGL。

## 本次改动

- 人类 A/D 移动通过绳约束牵动钩饵；钩饵具有速度、重力及水阻，停下后继续摆动并逐渐稳定。鱼线曲线表现滞后，真实钩尖、颗粒和接触判定共享实际钩位。
- W/S 收放线同时用于未上钩的深度调整及上钩后的拉锯。收至岸边取回当前钓组。Q 下钩，饵耗尽或断线后重新挂饵；新饵颗粒 ID 不与历史计分重复。
- E 持网，配合按住左键拖动实时控制网口方向。松开任一按键立即停止捕捉、沿实际走过的路径撤回；捕获后正常提鱼。取消不重置冷却，暂停会清除持网手势。
- F3 或设置面板可调低张力等待、松口 QTE 成功窗口及连续高张力断线时间。双方和练习通用，配置持久化，已开始的 QTE 保留开场时的成功区。

## 关键行为验证

- 停止移动后钩位继续向前，越过竿下平衡位置，随后水阻使其稳定；30/60/120 Hz 同一动作序列的终点差异小于 2 像素。
- W/S 调整未咬钩时的线长，持续 W 可以收回钩饵；Q 不能刷新仍有饵的在水钓组，不能清除上钩状态。
- 用尽及断线后补饵使用新颗粒 ID，保留已计分颗粒的历史，防止重新计分。
- 连续拖动会改变已经入水网口的方向，木石仍阻挡转向中的整圈网口；取消后沿曲线路径撤回，没有瞬移或返程捕捉。
- 入水准备阶段取消不会继续向水下运动。松 E、暂停与冷却的交互不会重新出网。
- 低张力等待时间控制 QTE 出现；成功区秒数控制真实判定与绘制宽度；连续高张力到设定时长才断线，张力下降清零计时。
- 无输入对抗时，AI 鱼实际吸食获得 60 食物并回巢。使用 Q、沿岸移动及 W/S 操作的完整模拟在约 38.53 秒提鱼获胜，经历 4 次咬钩，未直接修改鱼的位置、分数或结果。
- 手动网捕获带钩鱼后鱼线保持可见，完成收拢提网再结算。
