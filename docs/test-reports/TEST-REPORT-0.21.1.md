# 0.21.1 钩饵与散饵吸食表现统一

日期：2026-09-30。环境：Windows、Godot 4.7.2 / GL Compatibility。所有检查使用隔离的 `--test-profile`。

## 修正

0.21.0 的颗粒剥落和吸入已共用代码，但固定钩饵额外偏向鱼嘴，人操控钩饵还受到额外吸力加速度，鱼可以由整团位移识别钩饵。

本版取消这两处钩饵专属吸力。两类食物统一逐层剥落、颗粒移向嘴边，吸食不再额外移动饵团本体。钓具自身的重力、惯性及收放线继续运作，嘴部接触鱼钩仍触发吐钩 QTE。

原规则标识 `hook_suction` 为兼容个人方案 JSON v2 保留；选项改名为“饵粒吸入倍率”，统一影响所有脱落颗粒的吸入速度。默认值 1 保持原颗粒速度。快照 schema 10 与地图 `pond_v2` 保留；联机 build 改为 0.21.1，双方需要运行本版以使用一致模拟。
