# 0.15 岸边第一人称

日期：2026-09-27。Windows / Godot 4.7.2 / Compatibility OpenGL。

## 行为和实现

钓鱼人使用固定镜头，面向落日湖面。前景手掌、袖口、卷线轮和鱼竿由代码绘制，A/D 左右移竿；W/S 仍收放水下鱼线。鱼竿没有额外的上下或前后操作，鼠标上下移动不会调整鱼竿。受力时竿身弯曲，卷线轮随收放方向转动，浮漂有轻微水流起伏、咬钩下顿和挣扎波纹。水下鱼、木石与植物只画低对比轮廓，鱼越深越淡；隐藏人类 HUD 中对手的精确食物、体力及 AI 状态。QTE 仍位于左侧张力栏下方，使用空格。

新 `shore_view.gd` 只承担显示。以世界水面 y=55 对应屏幕浮漂横带 y=213，水下部分通过可逆二维变换绘制：`screen = (24, 213) + (world.x, world.y - 55) * (0.925, 0.35)`。实际水下物体的位置和碰撞没有随美术背景改变。抄网边沿、路线和鱼影采用同一变换；本地事件、每帧鼠标以及联机指令都先从屏幕转回世界坐标，保留同帧多个转弯的先后顺序。按住 E 显示可操作近水区和起点，木石仍阻网。鱼提离水面时恢复可见鱼身，线端跟随提鱼，不留在水面。小鱼视角继续使用原水下侧视。

湖面背景是内置图像工具生成的本地 PNG，绘制时最近邻采样，运行无需图像生成 API。完整提示词及制作方法见 `assets/first_person/GENERATION.md`。互动对象均由实际世界驱动，不烘焙在背景里。第一人称用于钓鱼人挑战、钓鱼人练习和真人联机。快照 schema 仍为 4，兼容标识更新为 0.15；联机双方需同版。

新版原生测试通过实际 Q、A/D、E、左键事件及 1280×720 窗口坐标进行操作，验证投影后的路径恰好还原到原世界折线，并在经过拐角后才进入下一段；释放 E 取消扫网。旧的有效原生测试仅将世界空间测试点投影到人类屏幕，菜单按钮仍用 UI 坐标。浮点坐标比较采用小于 0.01 像素的容差。旧 0.10.2 原生脚本是重构前直接更新世界的历史测试，保持归档，当前使用 0.11 指令缓存版。

截图核对浮漂、左右极限、模糊水下轮廓、手持鱼竿、受力 QTE、抄网路径和小鱼原画面。联机人类状态标记放到右上，避免遮住前景手和卷线轮。最终截图位于 `artifacts/shore-*-v015.png`，双进程截图为 `artifacts/effort-peer-*-v013.png`，后者已经用 0.15 发布包刷新。

测试使用 `--test-profile` 和独立配置路径，不写入玩家存档。本轮网络测试在同一电脑使用两个独立进程完成，未进行两台物理电脑的跨机测试。
