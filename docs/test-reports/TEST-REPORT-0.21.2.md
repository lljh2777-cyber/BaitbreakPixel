# 0.21.2 钩饵与散饵整团均可被吸动

日期：2026-09-30。环境：Windows、Godot 4.7.2 / GL Compatibility。所有检查使用隔离的 `--test-profile`。

## 修正

0.21.1 只让脱落颗粒进入嘴部，整团饵料不随吸食移动。本版改为钩饵和散饵的整团中心都向鱼嘴移动，并共用相同的吸力响应与速度。

`_step_bait_suction` 不读取钩饵身份，目标位移为吸食锥体强度 × 当前吸力 × 26 × `hook_suction`，以每秒 44 个逻辑像素平滑接近。吸力增大时位移更明显，松开后平滑回摆；位于锥体外的饵团不被吸动。附着颗粒和钩尖接触位置随实际中心移动，已脱落颗粒继续按原 `pellet_speed` 吸入。

每团饵保存 `suction_offset`，先移除上一帧偏移，再推进水流或原钓具运动，最后施加共同吸动，避免偏移逐帧叠加。咬钩和重新抛饵清零偏移。规则标识 `hook_suction` 保留以兼容 JSON v2；设置名为“饵团吸动倍率”。快照 schema 升为 11，联机 build 为 0.21.2，双方需运行本版。
