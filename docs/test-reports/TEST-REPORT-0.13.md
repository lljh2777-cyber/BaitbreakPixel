# 0.13 QTE 预警与人鱼发力

日期：2026-09-26。Windows / Godot 4.7.2 / Compatibility OpenGL。

## 判定与反馈

- 所有 QTE 开始前播放双音提示，提前 0.4 秒显示预警，再显示鱼钩形判定条。指针扫过轨道用时 2 秒，空格判定。
- 成功区在轨道的安全范围内随机分布，不再集中于原来的小段位置。入口及松线吐钩默认窗口为 0.24 秒；缠线为 0.24 秒；发力为 0.20 秒。
- F3 仍能将吐钩窗口调为 0.12—1 秒。旧配置首次按原值的 60% 迁移并受最小值限制，保存版本标记避免重复缩减。正在进行的判定保留开场宽度。
- 发力判定复用鱼钩轨道、浮漂和结果动画；结果后显示剩余加力／脱力时间。音效按角色分发，联机时不会播放对手的判定预警。

## 发力规则

- 只在鱼已上钩且未进入捕获／提鱼阶段生效。人类持续 W 收线、鱼有体力并逆着鱼线拉力游动时，有机会触发各自的发力 QTE；右键冲刺也计入鱼的发力。
- 上钩后的首次判定等待随机 1.2—2.8 秒有效发力时间。之后按随机等待触发，限制在 3—12 秒有效发力时间，并在上一轮力量效果结束后开始计时。短按、松开不会重新抽取等待时间。
- 成功后力量变为 135%，持续 2 秒；提前、错过或超时失败后力量变为 60%，持续 1.5 秒。停止发力不能取消已经出现的判定。
- 鱼的游动速度使用鱼的力量系数；收线和拉鱼使用人类与鱼力量系数的相对值。S 放线不受加力／脱力倍率影响，保留主动卸力能力。
- 发力期间持续允许移动、收放线和抄网。人鱼可以同时各自判定；普通吐钩、松线或缠线 QTE 优先于鱼的发力 QTE，抢占待判发力时不罚脱力。同一次空格不会同时完成发力并启动缠线。
- AI 通过同一判定命令参与，有成功及失败。暂停冻结计时；脱钩、被捕、提鱼、结算及重置清除临时力量状态。

## 联机同步

快照结构升级至 3，联机版本标识为 0.13，双方需使用同版。主机保留双方独立的判定历史，最多补偿 15 个模拟 tick（60 Hz 下为 250 毫秒），验证角色、判定类型及 ID；客户端自报判定时间被忽略，重复已解决判定不能重复获得力量。

原生双进程实测发现不可靠大快照可能延迟到判定结束才完整到达。现在判定开始／结束及力量状态变化立即发送可靠快照；判定、结果动画或力量效果期间使用 10 Hz 可靠状态，其余时间保持 30 Hz 不可靠状态。显示端的判定进度与输入携带的快照 tick 一致。
